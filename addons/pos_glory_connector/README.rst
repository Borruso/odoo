Installation
============

**After Installation**:

-  Go to **Settings > Glory Connector**:

   -  Set the **FCC URL** String (by default it's
      https://192.168.0.25/axis2/services/BrueBoxService so change
      192.168.0.25 by the real machine IP address but keep the
      "/axis2...Service" part)
   -  Check the **Sync time** checkbox to sync the machine time with the
      server time at POS startup

-  Go to **Point of Sale > Configuration > Payment Methods** and edit
   the **Glory Cash Machine** payment method by editing its journal
   entry to **Cash** if it's not set
